Source: distilled from HyperFrames skills by HeyGen (Apache-2.0): product-launch-video, hyperframes-creative.

1. HOOK (scene 1). It must create curiosity, tension or desire in the first 3 seconds, in outcome language: what the viewer gains. Never open with a company description ("ברוכים הבאים ל...", "הכירו את..."). Hook types, vary them between the 3 directions and never default to the same one: a sharp question, direct address ("את/ה"), naming the craving or pain, "תדמיינו...", a strong visual moment (the best photo + 2-3 words), or a concrete real number from the details (only if it carries stakes).
2. VALUE BY SCENE 2. The core promise lands by the second scene; everything after is evidence. Self-check: delete the evidence scenes and the remaining ones must still state the value.
3. PICK ONE ARC per direction and make the 3 directions use different arcs:
   - PAS: hook → craving/pain → solution (the product) → proof → offer → CTA.
   - Before/After: before → after tease → how → wow → CTA.
   - Feature→Benefit: category hook → feature → what it means for me → ... → climax → CTA. Always translate a feature into viewer value; never stack raw features.
   - Imagine: "תדמיינו..." → the moment → how it happens → result → CTA.
   For 20-30 s ads keep it lean: hook → one strong product moment → proof/offer → CTA. Do not force every fact into a short ad.
4. ONE JOB PER SCENE: hook, craving, product hero, craft/process, place, trust/proof, offer, CTA. Never "another feature". Give each scene a concrete persuasion move (social proof, risk reversal, rule of three, value stacking, urgency only if real) and a target emotion (curiosity → desire → trust → action).
5. HEADLINE = A CLAIM, NOT A LABEL. A specific claim (e.g. "בצק שתופח כל הלילה", only if the details or photos support it) beats a label like "המאפים שלנו". Lead with the punchline. Every claim must still come only from the business details or the photos.
6. VOICE follows the brand: calm/premium → fewer, aspirational words; bold/fast → short punchy words; warm/family → friendly direct address. Banned clichés: "חוויה שלא נשכחת", "איכות ללא פשרות", "הכי טוב בעיר", "פשוט מושלם".
7. TRACEABLE TO THE SOURCE: if a line could appear unchanged in another business's ad, rewrite it with this business's own words, products, numbers and photos.
8. CTA: the final scene is calm and confident: 1-2 short closing phrases landing on the CTA + website/phone. Risk-reversal lines work only if true. Don't add new energy at the end.
