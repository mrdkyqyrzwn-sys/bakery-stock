# Sources for adstudio-design-excellence

SKILL.md was written in our own words. It paraphrases ideas from the sources below and copies no text from them. All sources were read on 2026-10-21; the commit is listed next to each one.

| Source | What we took | License |
|---|---|---|
| Anthropic `frontend-design` skill: https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md (commit dbd4588) | Spend boldness in one place. Tells: eyebrow labels, one restyled headline word, cream + terracotta, near-black + one bright accent, identical cards, middle dots, arrows on buttons. Numbers only for real sequences. One orchestrated motion moment. Copy rules for errors and empty states. | Apache-2.0 (`skills/frontend-design/LICENSE.txt`) |
| Anthropic `canvas-design`, `theme-factory`, `brand-guidelines`, `web-artifacts-builder`: https://github.com/anthropics/skills/tree/main/skills | Minor: refine what exists instead of adding more. Avoid purple gradients, uniform corners and centered-everything. | Apache-2.0 (each skill's `LICENSE.txt`) |
| Anthropic cookbook "Prompting for frontend aesthetics": https://github.com/anthropics/claude-cookbooks/blob/main/coding/prompting_for_frontend_aesthetics.ipynb (commit a162e01) | Atmosphere and depth instead of flat fills. Dominant color with a sharp accent. One staggered page-load moment. | MIT (repo `LICENSE`, © 2023 Anthropic) |
| Impeccable by Paul Bakaus (v4.7.0): https://github.com/pbakaus/impeccable, `reference/craft-floor.md`, `animate.md`, `polish.md` (commit ca9c63a) | Quality floor: contrast, states, themed browser surfaces.
