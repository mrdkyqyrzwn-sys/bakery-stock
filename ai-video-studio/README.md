# סטודיו לסרטוני פרסומת ברמת חברת הפקה

אתר שבו בעל עסק מדביק כתובת אתר, מעלה תמונות (לא חובה), בוחר סגנון ואורך, משלם, ומקבל סרטון פרסומת מלא: **תסריט, קריין בעברית, מוזיקה מקורית ועריכה מקצועית של התמונות** (תנועת מצלמה, מעברים, כותרות, כתוביות מסונכרנות ומסך סיום). אם חסרות תמונות, המערכת יוצרת תמונות ריאליסטיות.

סרטון לדוגמה: `public/samples/pizza-roma.mp4` (עסק בדיוני, תמונות מ־Pexels. בדוגמה יש מוזיקה בלי קריין, ובמערכת האמיתית יש גם קריין).

## איך זה עובד

1. **סריקת האתר** (`/api/projects`): המערכת אוספת מדף הבית את הטקסטים, הצבעים, **הלוגו** (קודם מהנתונים המובנים של האתר, אחר כך מהכותרת העליונה, ובסוף מהאייקונים) ו**התמונות** (תמונת השיתוף, תמונות רקע ותמונות מוצר, כולל כאלה שנטענות בהמשך הגלילה). אחר כך Claude קורא את התוכן, בודק אותו מול מדיניות התוכן, כותב תקציר מותג וכותב קונספט בכל אחד מחמשת הסגנונות.
2. **תמונות** (`/api/projects/[id]/images`): הלקוח מעלה עד 12 תמונות. הדפדפן מקטין אותן ומוחק מהן את נתוני המיקום, והשרת בודק שזו באמת תמונה לפי התוכן של הקובץ.
3. **בחירה ותשלום**: המחיר מחושב בשרת, והתשלום עובר דרך Paddle, שהיא המוכר הרשמי (Merchant of Record).
4. **הפקה** (`worker/`), כמו חברת הפקה קטנה:
   - **תכנון**: Claude רואה את כל התמונות, גם אלה שהלקוח העלה וגם אלה מהאתר (בלי תמונות קטנות מ־500 פיקסלים), כותב תסריט מחולק לסצנות, מתאים תמונה לכל סצנה, בוחר קריין ומתאר את המוזיקה. בשלב הזה הוא גם דוחה תמונות לא ראויות.
   - **מדיה**: קריינות בעברית עם תזמון לכל מילה (ElevenLabs `eleven_v4`), מוזיקה מקורית באורך המדויק (ElevenLabs Music), ותמונות שחסרות (FLUX.2 Pro דרך fal.ai). אם הקריינות ארוכה מדי, המהירות שלה עולה מעט או שהתסריט מתקצר.
   - **עריכה**: Claude עורך את הסרטון בקוד מעל התמונות. כל חיתוך יושב בדיוק על תחילת המשפט, והכתוביות מסונכרנות למילים.
   - **בקרת איכות**: בדיקה טכנית בדפדפן מבודד, ואחריה Claude בודק צילומים מהסרטון ומתקן. זה קורה עד כמה סבבים.
   - **ייצוא**: Full HD ב־30 פריימים לשנייה. המוזיקה יורדת אוטומטית כשהקריין מדבר, ועוצמת הקול מנורמלת ל־‎-14 LUFS, התקן של הרשתות החברתיות.
5. כל שלב נשמר, אז ניסיון חוזר ממשיך מאיפה שעצר ולא משלם שוב על אותו שלב. **אם ההפקה נכשלת, הלקוח מקבל החזר כספי מלא באופן אוטומטי.**

## המבנה: שני חלקים

| חלק | מה הוא עושה | איפה הוא רץ |
|---|---|---|
| **האתר** (Next.js) | עמודים, סריקה, תשלום, webhooks, מחיקת נתונים | Vercel |
| **שרת ההפקה** (`worker/`) | תסריט, מדיה, עריכה, בקרת איכות וייצוא | שרת שרץ כל הזמן עם Chromium ו־ffmpeg, לפי `worker/Dockerfile` (למשל Railway, Fly.io, Render, בערך 5 עד 20 דולר לחודש) |

## הקמה

1. **מסד נתונים**: פותחים Postgres חינמי ב־[Neon](https://neon.tech) ומריצים:
   `psql "$DATABASE_URL" -f db/schema.sql`
2. **Claude**: מפתח API ב־[console.anthropic.com](https://console.anthropic.com).
3. **ElevenLabs** ([elevenlabs.io](https://elevenlabs.io)): מפתח API לקריינות ולמוזיקה. ב־Voice Library בוחרים שני קולות שנשמעים מעולה בעברית (קול של אישה וקול של גבר), ומכניסים את המזהים שלהם ל־`ELEVENLABS_VOICE_FEMALE` ול־`ELEVENLABS_VOICE_MALE`. כדאי לבדוק בתנאים של התוכנית שבחרת שמותר שימוש מסחרי בקול ובמוזיקה.
4. **fal.ai** ([fal.ai](https://fal.ai)): מפתח API ליצירת תמונות. דגמים יוצאים משימוש מדי פעם, אז כדאי לבדוק ש־`FAL_IMAGE_MODEL` עדיין פעיל.
5. **Paddle**:
   - פותחים חשבון ומשלימים אימות זהות ועסק. מתחילים ב־Sandbox.
   - יוצרים מוצר ("AI ad video"). המזהה שלו (`pro_...`) נכנס ל־`PADDLE_PRODUCT_ID`.
   - יוצרים API key ו־Client-side token.
   - ב־Notifications יוצרים webhook לכתובת `https://הדומיין/api/webhooks/paddle` עם האירועים `transaction.completed`, `transaction.paid`, `adjustment.created`, `adjustment.updated`.
6. **האתר ב־Vercel**: Root Directory = `ai-video-studio`, ממלאים את המשתנים מ־`.env.example` ומפעילים Vercel Blob.
7. **שרת ההפקה**: בונים ומריצים את `worker/Dockerfile` (מתוך התיקייה `ai-video-studio`) **עם אותם משתנים** (כולל `BLOB_READ_WRITE_TOKEN`). להרצה מקומית: `npm run worker` (דורש Chromium ו־ffmpeg).

## מצב דמו (בלי שום חשבון)

```bash
cd ai-video-studio
npm install
echo "NEXT_PUBLIC_DEMO_MODE=true" > .env.local
npm run dev
```
ופותחים את http://localhost:3000. כל המסלול עובד, מהסריקה ועד הסרטון, עם נתונים לדוגמה ובלי תשלום אמיתי.

## מחירים

`src/lib/pricing-core.ts`. עם ברירות המחדל (100% רווח על העלויות ועוד 5 דולר לסרטון):

| אורך | מחיר ללקוח | מה נשאר לך |
|---|---|---|
| 20 שניות | $12.99 | ~$8.20 |
| 30 שניות | $14.99 | ~$9.00 |
| 60 שניות | $19.99 | ~$11.40 |
| 2 דקות | $29.99 | ~$16.20 |

העלויות ב־`pricing-core.ts` הן הערכות: טוקנים של Claude, תמונות, קריינות, מוזיקה ורינדור. **אחרי 5 עד 10 סרטונים כדאי לבדוק את העלות האמיתית בלוחות הבקרה של Anthropic, ElevenLabs ו־fal, ולעדכן את המספרים.**

## אבטחה

- **תמונות שמועלות** מוקטנות בדפדפן, ונתוני המיקום נמחקים מהן. השרת בודק את סוג הקובץ לפי התוכן שלו, ויש מגבלה על הגודל ועל מספר התמונות. Claude דוחה תמונות לא ראויות, ואז ההזמנה מוחזרת.
- **הקוד ש־Claude כותב לא רץ על השרת.** הוא רץ רק בתוך ה־sandbox של Chromium, בלי אינטרנט (offline, כל הבקשות נחסמות, ו־CSP נעול). בדקתי קוד זדוני שניסה 9 דרכים שונות לצאת לאינטרנט או לשרת פנימי, ואף בקשה לא עברה.
- הגנת SSRF בסריקה ובהורדת תמונות: רק כתובות ציבוריות, ונבדקות שוב בכל הפניה ובזמן ההתחברות.
- המחיר מחושב רק בשרת. כל webhook של Paddle נבדק בחתימה ומטופל פעם אחת בלבד.
- גישה לפרויקט רק דרך קוד אקראי של 256 ביט, וכל המידע שנשמר עליו הוא hash.
- הגבלת קצב, בדיקת Origin, CSP, HSTS. לא נשמרות כתובות IP ולא שום דבר מכרטיס האשראי.
- מחיקה אוטומטית: טיוטות (כולל התמונות שהועלו) אחרי 7 ימים, תוכן האתר אחרי 30, וכל השאר (סרטונים, תמונות, קריינות ומוזיקה) אחרי 90.
- תוכן האתר מועבר ל־Claude כנתונים, עם אזהרה מפני הזרקת פרומפט.
